# M3. Shared Cognition & Interaction State Model｜共享认知与互动状态模型

版本 v0.5。状态：正式工程基线。

观察主体间信息、解释、模型、框架、分歧和共同背景。共享始终有对象、范围和确认依据。

Shared Information、Shared Meaning、Shared Model、Shared Frame 与 Agreement 分别记录。共享解释可以错误；准确理解可伴随持续分歧。

本模型登记 9 个接口：1 个 P 编号、8 个 Composite。P 表示当前工程粒度，不是心理机制不可再分的证明。

## 使用约定

条目机制映射均为工程解释候选；针对此目标的 CLE 干预效果默认 E0。Composite 的“组成”列表示可复用过程，不规定全部必经；已有输入直接复用。失败、无变化与信息不足都须保留。

<a id="i-p1"></a>

## I-P1. Sharedness Verification

**状态变化：** 假定共享 → 对指定内容具有足够确认依据。

按任务需要，用复述、新例、预测或操作反馈检查共享范围。

**完成检查：** 记录检查内容、方式和残余不确定性。

**边界与失效：** Verified Shared 的旧表述改为有范围的确认；复述不证明完全理解或事实真实。

**机制候选：** [ME10](../MECHANISMS.md#me10)。

<a id="i-c1"></a>

## I-C1. Shared Information Formation

**状态变化：** 信息不对称 → 相关主体获得任务所需共同信息。

传递相关材料并确认接收和可调用程度。

**完成检查：** 主体可引用同一版本材料，关键缺项和来源明确。

**边界与失效：** 共同持有与共同知道彼此持有不同；B-C2 是传递与互动的跨域过程引用，不是必须先完整完成的子步骤。

**可复用组成：** [I-P1](../models/M3.md#i-p1)。

**跨域过程引用：** [B-C2](../BRIDGES.md#b-c2)。

**机制候选：** [ME10](../MECHANISMS.md#me10)、[ME11](../MECHANISMS.md#me11)。

<a id="i-c2"></a>

## I-C2. Clarification

**状态变化：** 表达的多种未决解释 → 任务所需澄清。

明确歧义点、对象、例子、反例与条件。

**完成检查：** 对相关具体情境可一致判定所指。

**边界与失效：** 澄清是局部缩小歧义，不保证双方对所有方面一致。

**可复用组成：** [C-P3](../models/M2.md#c-p3)、[C-C1](../models/M2.md#c-c1)、[I-P1](../models/M3.md#i-p1)。

**跨域过程引用：** [B-C2](../BRIDGES.md#b-c2)。

**机制候选：** [ME10](../MECHANISMS.md#me10)、[ME11](../MECHANISMS.md#me11)。

<a id="i-c3"></a>

## I-C3. Meaning Alignment

**状态变化：** 不同解释 → 足够一致的解释。

比较各自主张含义，修正差异，并检查边界例。

**完成检查：** 双方能准确说明约定含义及未约定部分。

**边界与失效：** 理解一致不代表观点相同、标准相同或承担任务。

**可复用组成：** [I-C2](../models/M3.md#i-c2)、[I-P1](../models/M3.md#i-p1)。

**跨域过程引用：** [B-C2](../BRIDGES.md#b-c2)。

**机制候选：** [ME10](../MECHANISMS.md#me10)、[ME11](../MECHANISMS.md#me11)。

<a id="i-c4"></a>

## I-C4. Model Alignment

**状态变化：** 不同系统模型 → 任务所需的共同模型。

对实体、关系、边界与候选过程形成可检验的共同结构。

**完成检查：** 在约定范围共同采用同一结构，并能说明同一变化的预测；范围外差异另记。若仍有范围内模型冲突，只记录部分对齐或未达成。

**边界与失效：** 模型可共同错误；无需所有背景知识完全一致。

**可复用组成：** [I-C1](../models/M3.md#i-c1)、[I-C3](../models/M3.md#i-c3)、[I-P1](../models/M3.md#i-p1)、[C-P14](../models/M2.md#c-p14)。

**跨域过程引用：** [B-C2](../BRIDGES.md#b-c2)。

**机制候选：** [ME02](../MECHANISMS.md#me02)、[ME10](../MECHANISMS.md#me10)。

<a id="i-c5"></a>

## I-C5. Frame Alignment

**状态变化：** 不同问题范围／视角 → 共同工作框架。

协调本次讨论对象、目的、边界和分析维度。

**完成检查：** 能说明当前处理什么，以及保留哪些其他框架。

**边界与失效：** 框架共同使用不代表真实原因已被确定。

**可复用组成：** [I-C3](../models/M3.md#i-c3)、[C-P13](../models/M2.md#c-p13)、[I-P1](../models/M3.md#i-p1)。

**跨域过程引用：** [B-C2](../BRIDGES.md#b-c2)。

**机制候选：** [ME10](../MECHANISMS.md#me10)、[ME11](../MECHANISMS.md#me11)。

<a id="i-c6"></a>

## I-C6. Disagreement Structuring

**状态变化：** 笼统不一致 → 可定位的分歧。

区分事实、含义、证据、模型、价值、标准和行动选择差异。

**完成检查：** 每个分歧绑定对象与双方立场，并标共享部分。

**边界与失效：** 结构化不必消除分歧，不把强势者的说法当共同判断。

**可复用组成：** [I-C2](../models/M3.md#i-c2)、[C-P3](../models/M2.md#c-p3)、[C-P19](../models/M2.md#c-p19)、[I-P1](../models/M3.md#i-p1)。

**跨域过程引用：** [B-C2](../BRIDGES.md#b-c2)。

**机制候选：** [ME10](../MECHANISMS.md#me10)、[ME11](../MECHANISMS.md#me11)。

<a id="i-c7"></a>

## I-C7. Resolution State Formation

**状态变化：** 已定位分歧 → 一致、明确保留分歧或暂停。

确定哪些结论被接受、哪些待查、何时重开讨论。

**完成检查：** 参与者确认结果状态及其范围，允许不一致。

**边界与失效：** M3 的认可不同于 M4 承诺；沉默和疲倦不自动算同意。

**可复用组成：** [I-C6](../models/M3.md#i-c6)、[I-P1](../models/M3.md#i-p1)。

**跨域过程引用：** [B-C2](../BRIDGES.md#b-c2)。

**机制候选：** [ME10](../MECHANISMS.md#me10)。

<a id="i-c8"></a>

## I-C8. Common-Ground Updating

**状态变化：** 旧共同背景 → 更新且带状态的共同背景。

纳入新信息、含义、决定；撤回失效假设并记录版本。

**完成检查：** 可区分已确认、争议、失效及尚未共享的内容。

**边界与失效：** 共用文件不自动证明已阅读；共同背景不是客观真理库。

**可复用组成：** [I-C1](../models/M3.md#i-c1)、[I-C3](../models/M3.md#i-c3)、[I-C7](../models/M3.md#i-c7)、[I-P1](../models/M3.md#i-p1)。

**跨域过程引用：** [B-C2](../BRIDGES.md#b-c2)。

**机制候选：** [ME10](../MECHANISMS.md#me10)。
