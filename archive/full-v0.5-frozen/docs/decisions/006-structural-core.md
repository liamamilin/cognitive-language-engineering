# 决策006｜核心版必须保留母体系结构

日期：2026-10-01。子体系v0.2候选；项目快照project-v0.5.2；母体系Core v0.5保持初步冻结。

## 用户修正与问题

用户指出v0.1实用核心与原体系脱节。要求保留六原则、四类模型和各层结构，筛选其中高频、重要的具体组件与机制；不是另做一套泛用问句。v0.1将三问及六个动作升为主结构，虽有编号映射，仍不满足这个目标。

## 新取舍

保留九对象关系、M0总闭环、六原则与四模型。对81个模型接口、12个机制家族、34个算子和13套协议逐项给出教学／调用优先级。核心模型23项，组成／特化闭包及基本任务完成支撑8项，共31项。主讲机制7项、算子及主模式15项，完整协议PR05一套；其余保留升级入口。模型、机制与算子不是按同一个比例裁剪。

主讲项由跨日常任务复用、缺失后的关键损失及学习成本判断；支撑项由原组成／特化关系和基本任务所需交付／验收接口判断。不能删除依赖以制造20%的数字，也不能把所有机制候选映射当成操作执行依赖。

机制主讲选择不删除其余家族，也不更改组件原映射。算子选择可优先练其部分目标，例如OP23先练I-P1；不宣称完整共同背景更新已发生。完整PR05的使用算子均为核心，标准、评价、决策的组成闭包保留。其他协议不宣称被本版完整覆盖。

结构正文为docs/essentials/index.md；完整取舍审计为SELECTION.md，维护用审计不增加必学负担。原v0.5理论正文不改。首页入口仍位于阅读路线；独立页面改为按原则、模型、机制、工程、连接与评估导航。v0.5.1原包归档。
