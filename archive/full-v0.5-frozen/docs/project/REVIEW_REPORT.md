# v0.5 全体系复核

日期：2026-10-01。对象：v0.4 → v0.5。性质：正文审查、构造演练和交付验证；没有真实用户试验。

## 审查结果与改动

| 审查域 | 发现 | 修订位置 |
| --- | --- | --- |
| 核心架构 | 操作与候选机制表述仍易混同，影响在定义中遗漏 | CORE_SPEC、MECHANISMS |
| 状态证据 | 当前会做易被当本次获得；代理产物易被当主体能力 | STATE_SPEC、EVALUATION、RUN_SPEC |
| M1 | 编码产物与接收者理解须明确分开 | R-P5 |
| M2 | 无偏好、未采纳、无标准可能与停止混同；实施意图形成与执行混同 | C-P2、C-P17、C-C7、C-C8、C-C14 |
| M3 | 仅明确模型分歧也能被记为完成对齐 | I-C4，以及PR07 |
| M4 | 委派形成与运行条件及后续关闭阶段容易揉在一起 | 任务就绪四项检查、PR09、OP28 |
| 跨域关系 | 过程映射混入组成，双向引用像循环依赖 | M3/M4、BRIDGES、COMPONENT_SPEC、派生快照 |
| 算子与协议 | 多目标部分达成和未达成退出没有统一语义 | RUN_SPEC、全部13套协议、相关算子 |
| 语言模式 | 多对多关系主要是声明，读者需要可辨认情境 | LP36的三种用途与槽位检查 |
| 学习与应用 | Registry完整但主动选择与迁移训练偏薄 | MENTAL_MODELS、TRAINING、五例状态复核 |
| 失效与反馈 | 失败笼统，反馈被理解为必须修改 | FAILURE_ANALYSIS、OUTCOMES |
| 证据 | 来源到局部主张的对应缺清晰入口 | EVIDENCE_SPEC、sources/index |
| 维护与导出 | 快照仅检查名称，导出章数和版本硬编码 | update_registry、check_docs、export_book、版本记录 |

## 保留的结构

九核心对象、六基础原则、M1—M4、81登记接口、8个Bridge、3个Outcome、12个机制家族、34算子、36模式、13协议继续采用。本轮重点为语义和使用闭环，没有新增或撤销Transition。

初始72个ID和v0.4新增9个ID保留；4个特化继续复用。没有把这些编号宣称为81个独立心理机制。

## 检查类型

32项边界案例为桌面设计检查，五个应用例和使用规格中的轮次演练为构造示范。编号、链接、快照字段、构建与导出是技术检查；方法与研究效果另按评估规范。

本轮沿用来源核验深度，新增的是主张边界与组件对应，不报告新的文献效果或真实训练结果。电子书页面数量不代表理论质量；本版新增内容用于解释和调用原结构。

## 结论

v0.5 在原完整组件基础上，补足当前状态、变化、达成、退出和实际效果的区分，使学习者和维护者能够更明确地选择、检查与修改。当前仍是可检验工程基线；实际负担、因果效果与迁移等待独立材料，不被本次复核证明。
