# 003｜完整工程组件与证据范围

状态：已纳入 v0.4。依据：用户要求完成整套体系，而非继续交付候选章节。

决定：九对象均给出定义与对应正文；建立机制、算子、模式、协议、应用和评估闭环。所有卡片声明检查、边界、失败和停止方式。文档状态与证据状态分开，未做实证的工程内容保持 E0。

来源核验记录实际读取深度。偏好构造不简化为选择后的唯一现象；实施意图说明文与2006元分析是两个来源载体；书目核验不能当作全文证据。构造案例明确标示，结构验证不能包装成真实使用效果。

影响：本版可以用于学习、调用和产生可检验设计；后续效果研究与在线发布有各自验收条件，不以尚未完成这些事项否定工程基线已整合。
