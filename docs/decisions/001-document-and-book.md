# 决策 001：文档项目与在线电子书

日期：2026-10-01。状态：Accepted。

本页保留初始化决策。v0.4 已将候选研究整合进正式正文，当前目录不再同时展示旧候选章节；整合范围见决策 003。Markdown 单一来源和 GitHub Pages 阅读形式继续适用。

## 问题

CLE 将长期研究和反复修改。依赖聊天记录难以恢复正式定义、研究状态与修改理由；同时需要面向阅读者展示为电子书。

## 决策

Markdown 保存正文，Git 保存历史。六份上传文件是初始基线。研究稿、正式正文、项目状态与证据记录放在同一文档项目中，状态明确标注。

采用 MkDocs Material 构建网页电子书，后续提交到 GitHub，通过 GitHub Actions 与 GitHub Pages 发布。

## 理由

Markdown 可阅读、可比较，也便于任何 agent harness 维护。构建工具直接使用同一套正文，减少研究文档与展示书稿的同步成本。Git 保存历史快照，使“冻结后可修订”具有明确的历史依据。

## 影响

正文不需要立即改写为完整教材；研究阶段以规范和 Registry 为主。在线页面显示研究稿的候选状态。EPUB／PDF、网页历史版本切换和独立产品暂作为后续可选项。
