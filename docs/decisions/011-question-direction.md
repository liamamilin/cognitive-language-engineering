# 011｜核心句可直接使用，按缺口区分向外与向内

日期：2026-10-11。状态：用户同意后采用；完整规范仍为v0.7，项目快照project-v0.7.9。

## 问题与决定

指认的“先描述你注意到的情况，再找合适的称呼”是方法提示。读者有素材但不知道对象名称时，需要一句可交给他人或大模型的问题。另一些提问则为了调出、辨认或整理自己的已有观察和经验，二者的输入与回答责任不同。

核心句改为可直接自问、提问或表达的话；方法步骤仍留在方法说明，展开补素材、范围、处理和所求响应。逐项审查82接口与39语言模式正文。M1的9项分别呈现向外问法和向内自问；M2先用主体自问，6项确需新材料或外部建议的接口补向外变体；M3用实际交流确认，M4保留请求、提议、承诺及核验，不统一改问句。算子卡同步相同用途的核心句和必要变体。

## 边界与简化

向内提问也可能形成新理解，不预设读者其实已有完整答案。向外回答可能只整理原材料，不按是否问大模型判断知识来源。两种问法用于选当前表达，不新增模型、接口或学习层级，也不要求每项配两套。

指认名称未知时从素材和关注线索进入；连关注范围都未定时先列可选内容，由读者选择。偏好、目标采纳和选择由主体确认，M3的共同状态与M4的有效关系仍按原条件检查。大模型给出草稿只提供可检查产物，不自动证明读者理解、采纳或现实执行。
