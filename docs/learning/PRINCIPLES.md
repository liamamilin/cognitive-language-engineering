# Principle：七项原则

先掌握六项基础原则，再把P7作为贯穿体系的工程设计约束。它们包含建模区分、理论主张、局部经验命题与设计约束，证据性质不同。

| ID | 原则 | 要掌握的约束 | 一个容易出现的错误 |
| --- | --- | --- | --- |
| P1 | 表征原理 | 区分现实、内部表征与语言表达；检查来源 | 把展开标签时生成的细节当成已有事实 |
| P2 | 语境原理 | 联系主体、目的、前文、媒介、关系与状态理解表达 | 仅凭句式认定这句话在请求还是在承诺 |
| P3 | 共同背景原理 | 共享有对象、范围与确认依据；共享与真实分开 | 两人都同意，就认为事实已经证实 |
| P4 | 语言行动原理 | 按角色、来源、认可及既有规则检查社会关系成立 | 自称有权批准，就登记有效授权 |
| P5 | 语言介导认知原理 | 语言可参与部分认知工作；具体效果须检查 | 写出正确解释，就推定读者已掌握 |
| P6 | 形式敏感原理 | 形式可能影响加工和选择；改写不保证改善 | 更有说服力，就认为判断更准确 |
| P7 | 如无必要，勿增复杂 | 保留关键区别和检查能力，优先较少概念与步骤 | 为完整性补出任务并不需要的层级与表格 |

## P7的采用规则

新增或保留复杂性，应说明：删去它，哪个具体任务会出现什么判断错误、行动缺口或检查盲点？能由已有内容表达时先复用；不能说明必要作用时，优先合并、移至按需解释或删除。

必要性包括低频但后果重大的区别，不能只按频率删除权限、义务和因果依据。简单也不能以丢失来源、未知、拒绝或核验条件为代价。该原则是设计约束，未宣称普遍心理定律。

## 原则怎样连接模型

| 模型 | 特别需要理解的原则联系 |
| --- | --- |
| M1 表征 | P1区分表示与现实；P2指定用途；P6约束表达形式；P7限制不必要细化 |
| M2 个体认知 | P1区分产物与本人能力；P2/P5关注具体认知工作；P6提示形式影响；P7避免反复制造已有状态 |
| M3 共享互动 | P2明确交流语境；P3限定共享；P5/P6提示表达参与理解；P7只对齐任务所需范围 |
| M4 语言行动 | P2/P3处理接收与解释；P4检查有效成立；P7保留足够规格和必要认可 |

表中是学习重点，各原则可跨模型适用。下一步读[四模型](MODEL_GUIDE.md)；定义与原六原则的证据范围见[核心规范](../CORE_SPEC.md)。
